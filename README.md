# Грызлик — ИИ-питомец, который питается знаниями

Чат-бот в мессенджере MAX. Кидаешь ему тему или текст параграфа — он делает тест из 5 вопросов, показывает, что ты знаешь, а что западает, объясняет слабое место по-новому и двумя добивающими вопросами «закрывает» тему.

А ещё Грызлик — это питомец. За ответы он получает опыт и растёт: яйцо → малыш →
подросток → взрослый → мудрец. Каждый день без кормёжки — минус сытость, пропуск двух дней — минус уровень. В 18:00 бот напоминает покормить, а старые слабые темы предлагает повторить через 3 и 7 дней.

Как устроен внутри — в `структура_бота.md` и `структура_бота.pdf` (со схемами).
Команда из 4 человек, хакатон «Идея фикс», направление «Портал в будущее», номинация «Продвинутая разработка». Состав: [впишите имена].

## Запуск (Docker)

Нужны токен бота MAX

и ключ любого OpenAI-совместимого ИИ.

```bash
cd bot
cp .env.example .env        # вписать MAX_BOT_TOKEN и AI_API_KEY
docker compose up -d --build
```

Всё. Дальше в MAX находите бота и жмёте «Начать». Логи: `docker compose logs -f`,
ждём строку «Грызлик запущен, слушаю MAX…».

## Проверка кода

```bash
python -m pytest bot/tests/ -q     # 26 тестов, без интернета
```

## Что в папке

- `bot/` — код (Python + Docker), тесты, промты, картинки питомца
- `структура_бота.md`, `структура_бота.pdf` — экраны, переменные, блок-схемы
- `масштабирование.md` — что пришлось бы менять при росте числа учеников
- `ссылки.txt` — ссылки на бота и репозиторий
- `скриншоты/` — снимки экранов бота для защиты
