	# Грызлик — ИИ-питомец, который питается знаниями

Чат-бот в мессенджере MAX. Кидаешь ему тему или текст параграфа — он делает тест из 5 вопросов, показывает, что ты знаешь, а что западает, объясняет слабое место по-новому и двумя добивающими вопросами «закрывает» тему.

А ещё Грызлик — это питомец. За ответы он получает опыт и растёт: яйцо → малыш → подросток → взрослый → мудрец. Каждый день без кормёжки — минус сытость, пропуск двух дней — минус уровень. В 18:00 бот напоминает покормить, а старые слабые темы предлагает повторить через 3 и 7 дней.

Бот в MAX: https://max.ru/ideya_fiks_160_bot

Как устроен внутри — в `структура_бота.md` и `структура_бота.pdf` (со схемами).

Хакатон «Идея фикс», направление «Портал в будущее», номинация «Продвинутая разработка».

## Что нужно

- Docker (или Python 3.12, если без Docker)
- токен бота MAX
- ключ любого OpenAI-совместимого ИИ (OpenAI, OpenRouter, ProxyAPI, VseGPT и т.п.)

Ключи задаются в файле `bot/.env` — шаблон лежит в `bot/.env.example`.

## Запуск через Docker Compose

```bash
cd bot
cp .env.example .env        # вписать MAX_BOT_TOKEN и AI_API_KEY
docker compose up -d --build
docker compose logs -f      # ждём строку «Грызлик запущен, слушаю MAX…»
```

Остановить: `docker compose down`. База пользователей лежит в `bot/data/` и переживает перезапуск.

## Сборка и запуск контейнера вручную

```bash
cd bot
docker build -t grizlik .
docker run -d --name grizlik --env-file .env -v "$(pwd)/data:/app/data" grizlik
docker logs -f grizlik
```

В Windows PowerShell вместо `$(pwd)` — `${PWD}`.

## Запуск без Docker

```bash
cd bot
pip install -r requirements.txt
export MAX_BOT_TOKEN=токен_бота
export AI_API_KEY=ключ_ии
python bot.py
```

В Windows вместо `export` — `set MAX_BOT_TOKEN=...` и `set AI_API_KEY=...`.

Дальше в MAX находите бота и жмёте «Начать».

## Переменные окружения

| Переменная | Что это | По умолчанию |
|---|---|---|
| `MAX_BOT_TOKEN` | токен бота MAX | обязательно |
| `AI_API_KEY` | ключ ИИ-провайдера | обязательно |
| `AI_BASE_URL` | адрес OpenAI-совместимого API | `https://api.openai.com/v1` |
| `AI_MODEL` | модель | `gpt-4o-mini` |
| `REMIND_HOUR` | час напоминания | `18` |
| `TZ_OFFSET` | часовой пояс (Москва = 3) | `3` |

## Что в репозитории

- `bot/` — код (Python + httpx), `Dockerfile`, `docker-compose.yml`, `requirements.txt`, тесты, промты, картинки питомца
- `структура_бота.md`, `структура_бота.pdf` — экраны, переменные, блок-схемы
- `масштабирование.md` — что пришлось бы менять при росте числа учеников
- `ссылки.txt` — ссылки на бота и репозиторий
- `скриншоты/` — снимки экранов бота
